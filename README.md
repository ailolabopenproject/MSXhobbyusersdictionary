## MSXとは

MSXとは、ASCIIコーポレーションによって1983年6月16日に発表された標準化された家庭用コンピュータおよびビデオゲームシステムのアーキテクチャです。
当初はマイクロソフトが日本市場向けの製品として構想し、ASCIIコーポレーションの取締役である西和彦氏が共同で販売しました。マイクロソフトはこのプロジェクトを、当時のさまざまな家庭用コンピューティングシステムメーカー間で統一標準を作る試みとして構想しました。これは家庭用ビデオテープ機器のVHS標準と同様に思えます。一般に販売された最初のMSXコンピュータは、1983年10月21日に発売された三菱ML-8000で、これが公式なＭSXの発売日となりました。（wikipediaより抜粋）
MSXは日本で最も人気があり、他の国でも比較的人気がありました。MSXの売上については世界中でさまざまな報告があります。ある情報源は、日本だけで700万台を含む900万台のMSX販売を主張している一方、先述のASCIIコーポレーション創業者の西和彦氏は日本で300万台、海外で100万台が販売されたと主張しています。なお、マイクロソフトがついたにも関わらず、アメリカではMSXベースのマシンがほとんどリリースされませんでした。
しかしMSXは当時からコアなユーザー層もあり、MSX自体もMSX2が1985年に、MSX2+が1988年に、MSX3は1990年にとリリースされましたが（※MSXTurboRという後継機もありました）1995年を最後にMSX規格のパソコンは製造を終了しました。

2006年に1つのFPGAに機能を詰め込んだ1chipMSXが5000台限定で発売され、当時のユーザーを中心に現在でも根強い人気があります。
逸話のひとつとして、東西冷戦下の共産圏ではココム規制下で輸入できる数少ないパソコンの一つでもあったといわれています。(16ビット以上のパソコンは共産圏へは輸出できなかった)。旧ソ連が打ち上げた宇宙ステーション「ミール」には、制御用コンピュータとしてSONYのHB-G900(MSX2)が搭載されていたというエピソードは有名です。

## MSX、Restoreへ

昨今の世界的な半導体不足も叫ばれる中、いわゆるレトロPCも人気がありました。しかし初代が発売されてからはや40年が過ぎており、故障した場合の修理、或いは復活には当然ながら中古パーツしかありません。しかし、専用だったりどれとどれに互換性があるか等はなかなかに分かりづらい事です。
今回はまだ数こそ少ないものの、信頼性に重きを置いて総合的な辞書形態にするプロジェクトです。ただし、残念ながら2026年の現在では情報も次第に少なくなっており、失われる前にいかに情報を集められるかが鍵となります。
完全に個人趣味な為、穴も多いとは思いますが丁寧に進めていきたいと思っています。
